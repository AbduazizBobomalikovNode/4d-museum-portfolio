1. Bitta g'oya, restraint bilan

2025–26 g'oliblarining umumiy xususiyati: "one defended idea" — scene-logic (film kabi), page-logic emas. Og'ir effektlar faqat kerakli joyda. Static frame ham kuchli bo'lishi shart.

2. Erkin yurish — eng sevimli va eng tanqid qilinadigan model

Bruno Simon 2025 remake HN'da "CPU 100%, 30 s load, ma'lumot topilmaydi" deb tanqid qilingan. NN/g: guided tour + context-by-default yaxshiroq ishlaydi. → Hybrid navigatsiya: guided rail default + ixtiyoriy free-walk.

3. Stack konvergensiyasi

Three.js (WebGPU + TSL) + R3F + Rapier/BVH + GSAP(+Lenis) + Blender baked + Draco/KTX2 + Vite. Hammasi MIT/bepul (GSAP 2025-dan bepul).

4. "4D" = vaqt qatlami + portallar

"4D portfolio" brendi bo'yicha hech qanday precedent yo'q — bu imkoniyat. Eng yaxshi referenslarda vaqt allaqachon bor (Bruno 2025: fasllar + kun/tun; My Room: blended lightmaps). Portallar (drei MeshPortalMaterial / stencil) — non-Euclid xonalar uchun tayyor.

5. Blender = level editor, brauzer = renderer

Baked lightmaps + matcap, naming conventions orqali collider/spawn, tiered quality (detect-gpu), room = section, exhibit = deep link, HTML content 3D'dan tashqarida.

6. AI capture tayyor

Spark 2.0 (World Labs) Three.js ichida streaming Gaussian splat; Marble text→3D world (splat + collider mesh export). Haqiqiy xonani skanerlab "memory room" qilish mumkin.

05 · "4D" g'oyasi

Vaqt, portal, tesseract

Vaqt qatlami

Time-dial HUD slider: kun→tun, fasllar, "timeline corridor" — xonalar = yillar; yurgan sari arxitektura/yorug'lik yoshi o'zgaradi. Texnika: bir nechta baked lightmap'ni uniform bilan aralashtirish (My Room in 3D), drei Sky sunPosition, HDRI swap, ITom "baked global tint".

Portallar (non-Euclid)

drei MeshPortalMaterial (blend bilan kirish), drei <Mask> stencilRef swap, render-target + oblique clipping (Portal/Antichamber uslubi). Perf: ≤2 ko'rinadigan portal, half-res RT, offscreen'da o'chirish. Referens: thefrontdev stencil, Wawa Sensei tutorial, immersive-world-xi.vercel.app.

Tesseract hub

6 tekislikda aylanish (XY/XZ/XW/YZ/YW/ZW) + w-perspective → 3D. Logo/loader/atrium markazi; eshiklar = hypercube'ning 8 katagi (net). Refs: ciechanow.ski/tesseract, tsherif tesseract-explorer (WebGL2), topoviz.org, 4d.pardesco.com.

07 · Muzey UX

O'zlashtirishga arziydigan konventsiyalar

Xona = kategoriya

Entrance hall = intro/about; wings = loyihalar; lab = skills; corridor = timeline; gift shop = contact/CTA (Jesse: vending machine / arcade credits).

Plaque + audio guide

Har ekspanat yonida label (drei Html, occlude); ixtiyoriy curator narration (TTS/recorded) — NN/g "expert-led" tavsiyasi.

Inspect / diegetic UI

"Press E" / tap → modal; ekranlar ichida video (useVideoTexture) yoki iframe (Henry Heffernan CSS3D). HTML-in-Canvas API (Chrome 148–150 origin trial) — kelajakda live DOM texture.

Gamification (me'yorida)

Collectibles (Thibault: 10 ta), destructible logolar, easter egg, leaderboard. Dwell time ko'tariladi, lekin "wow tez so'nadi".

Loading & onboarding

Chunked Suspense + progress + "Enter" gate (audio unlock). Control hints shart. Loading'ni san'atga aylantirish (Ameen: sakura petals).

Liveness

Ghost avatarlar (PartyKit 10 Hz), global counter, "whispers" — kichik shared state ham joyni "yashaydigan" qiladi.
